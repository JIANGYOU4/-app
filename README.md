## 仓库结构

```
-app/
├── ui/        # UI 设计稿与界面资源
└── apps/      # 各个 App 项目源码
```

## 目录说明

| 目录 | 说明 |
|------|------|
| `ui/` | 存放 UI 设计稿、原型图、组件截图等界面相关资源 |
| `apps/` | 存放各个 App 的源代码项目，每个 App 一个子文件夹 |
